# WEEK03_Project

This project aims to simulate a New York real estate company to find properties that meet certain criteria for future clients. The main objectives are to understand the local market, the key factors that may drive up or down prices in NYC and where the most suitable properties for our clients are located.

We used 4 different datasets. The one that we used as a base was the New York Housing Market dataset from Kaggle, and then we used 3 others from the NYC OpenData:

- Criminal Activity Reports
- Schools in NYC
- Noise Complaints

By comparing these 4 data sets, we aim to find out if crime rate, proximity to schools and noise pollution impact NYC real estate housing prices.
